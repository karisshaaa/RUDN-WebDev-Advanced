# Proposal: Счётчики карточек по колонкам

## Problem

На доске не видно, сколько карточек в каждой колонке — приходится считать вручную, особенно когда карточек много и колонка не помещается на экране.

## Goal

Отображать количество карточек под названием каждой колонки в `BoardColumn`.

## Proposed Solution

### Подход: счётчики в `BoardColumn`

```
App.tsx
  │ cards: Card[] (state)
  │
  ├── toDo = cards.filter(c => !c.isDone)
  ├── inProgress = cards.filter(c => c.isDone && !c.isUrgent)
  └── done = cards.filter(c => c.isDone && c.isUrgent)
        │
        └── <BoardColumn cards={toDo}   count={toDo.length}   title="К выполнению" />
        └── <BoardColumn cards={inProg} count={inProg.length} title="В процессе" />
        └── <BoardColumn cards={done}   count={done.length}   title="Готово" />
```

1. `App.tsx` группирует карточки по статусу (`isDone`, `isUrgent`).
2. Передаёт `count` как пропс в `BoardColumn`.
3. `BoardColumn` отображает `count` под заголовком колонки.
4. Счётчик обновляется автоматически при любом изменении `cards`.

## Scope

### In scope
- Отображение количества карточек под названием каждой колонки
- Группировка карточек по статусу в `App.tsx`
- Обновление счётчиков при изменении состояния карточек

### Out of scope
- Серверная часть
- Фильтрация / поиск карточек
- Drag & drop (будущее расширение)
- Настройка названий колонок

## Risks

- **Низкий** — изменения только на клиенте, `BoardColumn` уже принимает `cards[]`.
- Нет зависимостей от бэкенда.

## Impact

| Файл | Изменение |
|------|-----------|
| `client/src/types/card.ts` | Без изменений (используется `isDone`, `isUrgent`) |
| `client/src/App.tsx` | Группировка `cards` по статусу, передача `count` в `BoardColumn` |
| `client/src/components/BoardColumn/BoardColumn.tsx` | Добавить пропсы `count` и `title`, отобразить |
| `client/src/components/BoardColumn/BoardColumn.module.css` | Доп. стили для заголовка и счётчика |
